Core Concepts

What it means: Git is a local version control tool tracking code history. GitHub is a cloud platform hosting Git repos with Pull Requests and Actions.
Why developers use it: Prevents overwriting teammates' work and enables remote team collaboration.
git init   # tracks project locally before pushing to GitHub
What it means: A repository stores project history. The working directory holds files you edit; the staging area prepares selected changes for the next commit.
Why developers use it: Lets you group clean, related edits together instead of committing half-finished debug code.
git add src/ProfileBadge.js
What it means: A commit is a permanent snapshot. main holds stable production code; a feature branch isolates one task.
Why developers use it: Keeps main always deployable while you build and test.
git checkout -b feat/user-profile
