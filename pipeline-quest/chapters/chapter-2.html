Chapter 2: Commit and Push

Day 1 · Afternoon — Sharing Your Work
Your feature is ready locally on feat/user-profile, but your teammates and CI server cannot see it until you stage, commit, and push it to GitHub (origin).

Core Concepts

What it means: Your local repo lives on your machine; origin is the remote repository on GitHub. git push uploads commits; git pull downloads teammates' commits.
Why developers use it: Fast offline commits locally, synchronized collaboration via GitHub.
git push -u origin feat/user-profile
What it means: Inspect changes (status), stage files (add), record a snapshot (commit), and upload to GitHub (push).
git status && git add . && git commit -m "feat: add badge" && git push
