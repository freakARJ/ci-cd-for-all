Chapter 3: GitHub Actions — Automation Begins

Day 2 · Opening Your Pull Request
Your branch reached GitHub and you opened a Pull Request. Instantly, a workflow defined inside .github/workflows/ci.yml starts running without anyone clicking a manual test button.

Core Concepts

What it means: GitHub Actions automates CI/CD directly inside GitHub using YAML workflow files stored in .github/workflows/.
.github/workflows/ci.yml
What it means: The on: key defines what starts a workflow: pushing commits, opening/updating a Pull Request, or clicking Run manually.
on:
  push:
    branches: [main]
  pull_request:
  workflow_dispatch:
